# C - Recursion

This project covers recursion in C: functions that call themselves.

## Tasks

* 0. `_puts_recursion` - prints a string, followed by a new line.

## Requirements

* Compiled on Ubuntu 20.04 LTS with gcc (-Wall -Werror -Wextra -pedantic -std=gnu89)
* Betty style
* No loops, no global or static variables, no standard library
